# cstj_remote_drive

[![Github Actions Status](https://github.com/CSTJ-SN1/CSTJ-SN1.github.io/workflows/Build/badge.svg)](https://github.com/CSTJ-SN1/CSTJ-SN1.github.io/actions/workflows/build.yml)

Stockage distant des fichiers étudiants pour JupyterLite (420-SN1)

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install cstj_remote_drive
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall cstj_remote_drive
```
