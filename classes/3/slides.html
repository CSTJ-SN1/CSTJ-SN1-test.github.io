Nombres aléatoires

Plusieurs fonctions sont disponibles pour générer des nombres pseudo-aléatoires. Pour les ajouter à notre projet, on ajoute cette ligne en haut:

import random

Fonction Type
random.random() Entre 0 et 1 float
random.randint(a, b) Entre a et b int
random.uniform(a, b) Entre a et b float

Tortue avec Python

Comme pour le random, il faut d'abord ajouter le fichier les fonctions à notre projet.

import tortue

Puis on crée la zone de dessin (important!)

tortue.nouveau(100, 100)

Les grandes lignes de cette librarie

tortue.nouveau(100, 100, False) # Crée un canvas

tortue.afficherTortue() # Facultatif

# =-=-=-=-=-=-=-=-=-=-=-=-=-=
# Commandes de la tortue ici...
# =-=-=-=-=-=-=-=-=-=-=-=-=-=

tortue.afficher()

Commandes de la tortue

Nom Exemple
avancer(distance) tortue.avancer(10)
tourner(degrees) tortue.tourner(90)
tournerAZero() tortue.tournerAZero()
appuyerCrayon() tortue.appuyerCrayon()
leverCrayon() tortue.leverCrayon()
changerTailleCrayon(taille) tortue.changerTailleCrayon(5)
changerCouleurCrayon(couleur) tortue.changerCouleurCrayon("red")

Afficher le résultat de la tortue

On peut choisir si la tortue sera visible sur le dessin:

tortue.afficherTortue() # facultatif

Finalement, pour afficher le dessin de la tortue, on utilise:

tortue.afficherDessin()

Les boucles

Notre prochaine structure de contrôle est la boucle.

Elle permet de répéter une partie de notre code un certain nombre de fois.

print("Dans mon cours de Python, je devrais...")

for nombre in range(0, 4):
    print("Pratiquer")

print("Et avoir du plaisir!")

Un exemple déconstruit

for nb in range(0, 3):
    resultat = 10 + nb
    print(resultat)
nb = 0
resultat = 10 + nb
print(resultat)

nb = 1
resultat = 10 + nb
print(resultat)

nb = 2
resultat = 10 + nb
print(resultat)

Boucle while

La boucle while est une autre façon de répéter notre code. Tant que la condition qui suit le while est True, la boucle se répète.

i = 1

while i < 1000:
    i = i * 2
    print(i)

Il faudra toujours modifier une variable de la condition dans la boucle pour éviter une boucle infinie.
