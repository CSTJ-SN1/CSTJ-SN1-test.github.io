Exercices - Cours 6

  1. Affichez deux nombres aléatoires (peu importe lesquels) dans un texte à l'aide d'un "f-string"

  2. Demandez à l'utilisateur d'entrer un nombre qui représente un nombre de lettres.

    Affichez les noms masculins fournis par le gouvernement qui ont exactement le nombre de lettres demandé par l'utilisateur.

  3. Demandez à l'utilisateur d'inscrire son nom et le sauvegarder dans un nouveau fichier de votre choix. Le nom s'ajoutera à la fin sans écraser les noms précédents.

  4. Afficher chaque nom d'utilisateur ajoutés dans le fichier du problème précédent. Chaque nom devrait être précédé par : "👤".

    Par exemple:

    👤 Eric
👤 Amélie
👤 Iris

  5. Dans le fichier liste_a.csv, trouvez le nombre le plus grand par programmation.
  6. Dans le fichier liste_a.csv, quelle est la différence entre le plus grand et le plus petit nombre?
  7. Dans le fichier liste_a.csv, quelle est la moyenne?
  8. Créez un fichier avec 500 nombres aléatoires entre 0 et 100. Chaque nombre doit être écrit sur une ligne.
  9. Tracez une ligne avec chaque valeur écrite dans le fichier du problème précédent comme valeur en y.
  10. Utilisez un des CSV fournis par le gouvernement pour afficher une statistique de votre choix sous forme de graphique.
