Tests de code

Les "tests" sont des bouts de code qui valident le bon fonctionnement du reste du code.

def addition(a, b):
    return a * b # Oops, une erreur ici!

assert addition(10, 20) == 30, "Ajout de 10 et 30"

assert 10 > 5, "Message d'erreur"
