Les fonctions

En programmation les fonctions sont:

  • Un nom associé à du code
  • Une logique réutilisable
  • Le traitement des valeurs d'entrées pour produire un résultat

Structure d'une fonction - Déclaration

L'utilisation des fonctions est divisée en deux parties.

On peut déclarer une nouvelle fonction:

def sqrtOuZero(n):
    if n > 0:
        return math.sqrt(n)
    else:
        return 0

Structure d'une fonction - Appel

On peut aussi appeler une fonction existante:

a = sqrtOuZero(25)
b = sqrtOuZero(10)
c = sqrtOuZero(-159)

Paramètres - Les valeurs d'entrées

Une fonction peut avoir une quantité de valeurs d'entrées variable.

# Aucun paramètre
random.random()
tortue.afficher()

# Un paramètre (très commun)
print("test")
math.sqrt(25)
tortue.avancer(50)

# Deux paramètres (très commun)
tortue.nouveau(100, 100)

# Encore plus!
tortue.rectangle(10, 10, 30, 30)

Les paramètres seront reçus dans les parenthèses de la fonction

def rectangle(x, y, largeur, hauteur):

return - La valeur de sortie

  • Une fonction sans return retournera tout de même la valeur None
  • Dès qu'une ligne return est exécutée, la fonction se termine.
  • Une fonction peut retourne une seule valeur de n'importe quel type. Ce qui inclus les listes!

Ordre d'exécution

def test(texte):    # <---╮
    print("B")      # 2   |
    print(texte)    # 3   |
    # --------------------|---╮
                    #     |   |
print("A")          # 1   |   |
test("C")           # ----╯   |
print("D")          # 4  <----╯
# A
# B
# C
# D

Une fonction doit toujours être
déclarée avant d'être utilisée.
