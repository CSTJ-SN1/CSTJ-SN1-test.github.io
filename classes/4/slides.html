Les listes

  • Suite de valeurs
  • Contenus dans une seule variable
  • Types peuvent variés
  • Syntaxe: [10, True, "Item"]
  • Débute avec un index de 0

#                  0         1       2
personnages = ["Frieren", "Fern", "Stark"]

print( personnages[0] ) # Frieren
print( personnages[1] ) # Fern
print( personnages[2] ) # Stark

Ajouter à une liste existante

On peut ajouter une nouvelle valeur à une liste avec .append(valeur)

positions = [42, 100]
        
positions.append(142)
positions.append(200)

#   0   1    2    3
# [42, 100, 142, 200]

Supprimer un index dans une liste

On peut supprimer un index avec .pop(index)

#             0   1    2    3
positions = [42, 100, 142, 200]

positions.pop(2) # Enlève 142

#                             0   1    2  << changé!
# positions vaut maintenant [42, 100, 200]

Longueur d'une liste

On peut savoir combien de valeurs sont dans une liste avec len(liste)

#       0    1    2
nbs = ["a", "b", "c"]
quantite = len(nbs) # 3

On remarque que le len() sera toujours 1 de plus que le dernier index.

Boucles avec une liste

Les listes sont presque toujours utilisées avec les boucles.

Il existe deux façons de traiter chaque élément d'une liste.

Boucle avec liste

Version courte

noms = ["Alexa", "Amélie", "Arya"]

for nom in noms:
    print(nom)

Boucle avec liste

Version longue (avec index)

noms = ["Alexa", "Amélie", "Arya"]

quantite_noms = len(noms) # 3

for index in range(quantite_noms):  # range(3)
    nom = noms[index] # << La ligne magique 
    print(str(index) + ": " + nom)

Dessiner des formes

Une autre librairie de code qui utilise matplotlib est disponible pour dessiner des formes.

On pourra l'utiliser pour afficher des formes géométriques variées.

Les grandes lignes de cette librarie

Commandes

Configuration du dessin

Il est aussi possible de modifier certaines informations en lien avec le dessin.

dessin.couleur_bordure = "#00FF00"
dessin.largeur_bordure = 2
