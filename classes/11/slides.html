Numpy

La librairie Numpy permet, entre autres:

  • Créer des listes avec des superpouvoirs
  • Manipuler nos données numériques avec aise
  • Obtenir de meilleures performances

Utilisation de Numpy

import numpy as np

Puisqu'on réutilisera souvent le mot numpy, il est courant de l'abréger à np

np.array

Converti une liste en array Numpy

a = np.array([0, 1, 2, 3])

print(a)        # [0 1 2 3]
print(type(a))  # <class 'numpy.ndarray'>

print(a[0])     # 0
print(a[-1])    # 3

np.arange (array range)

Crée une séquence.

Contrairement à range, np.arange permet d'obtenir des floats!

a = np.arange(2, 5, 0.5)

print(a) # [2.0  2.5  3.0  3.5  4.0  4.5]

.reshape

Divise les valeurs en plusieurs array.

Doit être utilisé sur une variable contenant un Numpy array.

noms = np.array(["Vex", "Jester", "Vax", "Caleb", "Nott", "Scanlan"])
groupes = noms.reshape(3, 2) # 3 groupes de 2

print(groupes)
# [['Vex' 'Jester']
#  ['Vax' 'Caleb']
#  ['Nott' 'Scanlan']]

np.linspace (linear space)

Divise un interval en séquence.

a = np.linspace(0, 10, 5) # de 0 à 10 en 5 valeurs

print(a) # [ 0.0  2.5  5.0  7.5  10.0 ]

Aléatoire avec Numpy

Numpy offre la possibilité de créer une séquence de nombres aléatoires constants.

rng = np.random.default_rng(424242) # 424242 est le "seed"

n1 = rng.random()           # Toujours les mêmes valeurs pour un même "seed"
n2 = rng.integers(-10, 10)
n3 = rng.uniform(-10, 10)

On peut aussi ajouter demander une quantité d'aléatoires en array.

np.random.uniform(-10, 10, 50) # 50 nombres

Fonctions mathématiques sur des array

Contrairement aux listes, il est possible d'appliquer certains opérateurs à chaque élément d'un array Numpy.

a = np.array([0, 1, 2.5, 20])

b = a * 2 # [0, 2, 5, 40]
c = np.sin(a) # Crée un array avec sinus appliqué chaque item

Dimensions multiples dans nos listes

Le concept de dimensions multiples consiste à imbriquer des listes dans des listes.

a = [
    [1, 2, 3],
    [10, 20, 30],
    [1000, 0, 0],
]

Pour les utiliser, on enchaine les index.

print( a[1][2] ) # 2e ligne, 3e colonne : 30
