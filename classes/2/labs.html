Exercices - Cours 2

  1. Créez une variable lumiere_allumee avec une valeur de type bool de votre choix.

    Si la variable lumiere_allumee est à True, afficher: Il fait clair.

    Sinon, afficher: Il fait noir.

  2. Permettre à l'utilisateur d'entrer 3 nombres. Trouvez ensuite la moyenne des 3 nombres entrés.

  3. Une facture de 72$ est présentée à votre table.

    Permettez à l'usager d'entrer un montant de pourboire.
    Par exemple 15%

    Avec ce montant, affichez le montant de pourboire résultant.

    Affichez aussi le montant final de la facture (72$ + le pourboire calculé).

  4. Créez une variable de chaque type de valeur connue jusqu'ici. Essayez ensuite de construire une phrase avec ces variables.

    Par exemple: Mon nom est Eric, j'ai 3 chats, dormi 7.5h et le fait que j'enseigne la programmation est: True

  5. Permettre à l'utilisateur d'entrer une température en Celsius et afficher la température correspondante en Fahrenheit.

  6. Avec le code de départ ci-dessous, trouvez une façon d'échanger a et b de sorte qu'à la fin a soit 100 et b 20. 

    a = 20
b = 100
c = None

    Contrainte: Vous devez manipuler les variables sans écrire de nouveaux nombres. Par exemple a = 100 serait inacceptable.

  7. Chaque session, un(e) ami(e) vous demande de calculer la moyenne dont il a besoin pour les examens restants afin de passer son cours. Vous décidez de faire un programme qui lui répondra automatiquement.

    Votre programme doit:

    • Demander les points accumulés à ce jour
    • Demander le nombre de points évalués à ce jour
    • Calculer la moyenne requise pour les points restants afin d'obtenir 60 à la fin de la session

    Par exemple, si un étudiant a 26 points sur 40 d'accumulés, il lui faudra encore 34 points sur les 60 restants, donc une moyenne de 56.666%.

  8. À partir d'un nombre de secondes depuis minuit entré par un utilisateur, calculez l'heure arrondie.

    Par exemple, si l'utilisateur entre 28800, cela est équivalent à 8h00.

    Avec cette heure, affichez "jour" ou "nuit". Si l'heure est entre 6h et 18h, c'est le jour. Sinon, c'est la nuit.

  9. Pour l'équation quadratique ax^2+bx+c = 0, la formule est:

    \frac{-b \pm \sqrt{b^2-4ac}}{2a}

    Convertissez cette formule en code.

    Pour vos tests, utilisez:

    a = 3
b = 5
c = -7

    Bonus: Ajoutez des input() pour les variables a, b et c. Attention de bien convertir le type de valeur!
