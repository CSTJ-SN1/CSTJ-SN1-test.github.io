Commentaires de code

Dans Jupyter, il existe deux façons d'ajouter des informations pertinentes autour de notre code.
  1. Ajouter un bloc "Markdown" avant un bloc de code.
  2. Ajouter un commentaire directement dans le code à l'aide du symbole # 
    # Constante PI
pi = 3.14159265

Pourquoi des commentaires?

Plutôt que de décrire en français le code, il faut plutôt indiquer son sens et/ou sa raison d'être.

Entrée utilisateur

Pour certains programmes, il est utile de permettre à l'utilisateur de personnaliser certaines valeurs.

On utilise la fonction input() qui sera remplacée par la valeur entrée par l'utilisateur.

age_texte = input("Entrez votre age")
age = int(age_texte)
print(age)

Les valeurs reçues seront toujours de type str. Il faudra, au besoin, les convertir.

Obtenir un booléen

Opérateur Exemple
< Plus petit 5 < 10
<= Plus petit ou égal 5 <= 10
> Plus grand 10 > 5
>= Plus grand ou égal 10 >= 5
== Est égal 10 == 10
!= N'est pas égal 10 != 20
and ... Et ... True and True
or ... Ou ... True or False
not Inverse le booléen not False

Condition if

Il est possible de rendre l'exécution de certaines parties du code restrictives.

On parle alors de structure de contrôle.

if age >= 18:
    print("Vous êtes majeur")
else:
    print("Vous êtes mineur")

jour = input("Quel jour de la semaine?")

if jour == "samedi" or jour == "dimanche":
    print("Dormir...")
    print("Jouer à l'ordinateur")
    print("Faire du sport à -8000°")
else:
    print("Aller à mes cours")
    print("Discuter avec mes collègues")

print("Pratiquer mon Python 😇")

Versions alternatives du if

Sans else

if vies <= 0:
    print("Perdu!")

Plusieurs conditions

if mois == "janvier":
    print("Bonne année!")
elif mois == "décembre":
    print("Joyeux Noël!")
else:
    print("🚫 Mariah Carey 🚫")
