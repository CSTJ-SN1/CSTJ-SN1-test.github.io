Types de valeurs

  • int: Nombre entier (10, 42, -5, ...)
  • float: Nombre avec décimale (10.0, -2.32, 3.14159, 0.0001, ...)
  • bool: Booléen (True, False)
  • str: String/Texte ("Allo", "Chat", "", ...)
  • None: Aucune valeur (None)

type(???) permet de connaitre le type d'une valeur

Variables

On peut nommer un espace en mémoire pour y assigner une valeur et la lire ensuite.

a = 10
b = 32
c = a + b # Équivalent à 10 + 32
print(c)

Nom des variables

Le nom de nos variables doit respecter certaines contraintes.

Nous devons:

  • Débuter par une lettre minuscule (a-z)
  • Le composer de lettres (a-z ou A-A), chiffres (0-9) et barres soulignées (_)

Certains noms sont aussi réservés par Python.
