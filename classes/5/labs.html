  9. Soyez créatif avec l'outil de voxel!

    Voici un modèle d'exemple dans lequel vous pouvez changer le calcul et la condition pour des résultats très différents!

    import matplotlib.pyplot as plt
import math

fig = plt.figure()
ax = fig.add_subplot(projection="3d")

voxels = []

for x in range(14):
    for y in range(14):
        for z in range(14):
            # Distance
            calcul = math.sqrt((x - 7)**2 + (y - 7)**2 + (z - 7)**2)
            
            # Absolue de la distance est pas trop loin du centre?
            if abs(calcul) < 7:
                # On ajoute le voxel
                voxels.append([x,y,z])

for voxel in voxels:
    ax.bar3d(voxel[0], voxel[1], voxel[2], 1, 1, 1)

plt.show()

    Quelques formules à essayer:

    sin(x) + sin(y) + sin(z) >= 1.2

    sin(\sqrt{x^2+y^2+z^2}) > 0.2
