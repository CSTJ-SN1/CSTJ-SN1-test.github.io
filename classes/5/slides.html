Matplotlib - Graphiques

Dans un objectif plus sérieux, Matplotlib s'utilise pour visualiser nos données.

Créer un graphique

import matplotlib.pyplot as plt

fig = plt.figure()
ax = fig.add_subplot()

# Instructions ici

ax.set_title("Titre du graphique")
ax.set_xlabel("Axe des X") 
ax.set_ylabel("Axe des Y") 

plt.show()

Tracer une ligne

x = [0, 1, 2, 3, 4]
y = [0, 1, 4, 9, 16]

ax.plot(x, y)

On peut aussi changer le style avec une troisième valeur.

ax.plot(x, y, "o-")

Liste complète

Diagramme à barres

x = ["A", "B", "C", "D"]
y = [2, 7, 4, 6]

ax.bar(x, y)

Diagramme circulaire

y = [35, 25, 25, 15]

ax.pie(y)

Ou encore avec des libellés:

y = [25, 15, 35, 5]
labels = ["A", "B", "C", "D"]

ax.pie(y, labels=labels)

Un exemple plus complexe

import matplotlib.pyplot as plt
    import random
    
    fig = plt.figure()
    ax = fig.add_subplot(projection="3d")
    
    voxels = []
    
    for i in range(100):
        x = random.randint(0, 10)
        y = random.randint(0, 10)
        z = random.randint(0, 10)
        voxels.append([x, y, z])
    
    for voxel in voxels:
        ax.bar3d(voxel[0], voxel[1], voxel[2], 1, 1, 1, color="#FF00FF")
    
    plt.show()
