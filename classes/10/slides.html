Fichiers .py externes

Il est possible de segmenter notre code en plusieurs fichiers.

Ces fichiers secondaires:

  • Ont une extension .py
  • Contiennent seulement des fontions
  • Doivent faire leurs propres import

Exemple de fichier externe

# Fichier: geometrie.py
import math

def circonference(radius):
    return 2 * math.pi * radius

# Fichier de Notebook .ipynb
import geometrie

c = geometrie.circonference(10)
print(c)

Pour s'assurer que le contenu des fichiers externes est rechargé, il faudra ajouter quelques lignes:

import importlib
import mon_fichier

importlib.reload(mon_fichier)

Vous devrez aussi redémarrer le kernel une fois après avoir créé le fichier .py

Le type dict

  • Groupe de valeurs (similaire aux listes)
  • Contenus dans une seule variable
  • Types peuvent variés
  • Les clé (index) peuvent être de n'importe quel type
  • Pas de début ou de fin

Créer un dict

personne = { "prenom": "Kevin", "nom": "Tremblay" }

element = { 
    "nombre": 27, 
    "symbole": "Co", 
    "nom": "Cobalt", 
    "masse": 58.933194,
}

Utiliser un dict

On utilise la clé (index) donné dans les [] comme les index numériques de listes.

p = { "prenom": "Kevin", "nom": "Tremblay" }

print( p["prenom"] )

Ajouter un item dans un dict

mots = {}

# AJOUT
mots["test"] = 1

print(mots)

Supprimer un item dans un dict

lettres = {"A": 10, "B": 20}

# SUPPRIME
lettres.pop("A")

print(lettres)

Vérifier si une clé est dans un dict

lettres = {"A": 10, "B": 20}

if "C" in lettres:
    print("Oui")
else:
    print("Non")

Boucle sur un dict

Il est possible de faire une boucle sur un dict. Nous aurons alors accès aux clés.

liste_prenoms = {"Eric": 35, "Amélie": 25, "Iris": 30}

for prenom in liste_prenoms:
    age = liste_prenoms[prenom]
    print(f"{prenom}: {age}")
